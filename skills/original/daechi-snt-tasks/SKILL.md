# 대치SNT학원 할일 → 노션 자동 기록 스킬

Jenny님이 대화 중에 학원 운영 관련 할일을 언급하면, 그 즉시 노션의 정해진 위치에 기록한다.
"할일에 추가해줘"처럼 명시적으로 요청하지 않아도, 학생/선생님 이름 + 처리해야 할 액션(전화,
문자 발송, 결제, 확인, 구매/준비 등)이 대화에 나오면 먼저 물어보지 말고 바로 기록하고, 기록한
뒤 한 줄로 어디에 넣었는지 알려준다 (조용히 넘어가지 않는다 — 잘못 분류됐으면 바로 고칠 수 있게).

**주의 — daechi-snt-calendar 스킬과 용도가 다르다.** 학생 결석, 선생님 휴강/보강, 학원 공식
일정(설명회, 방학, 시험기간 등)처럼 행정팀과 공유해야 하는 내용은 이 스킬이 아니라
daechi-snt-calendar 스킬(구글 캘린더)로 보낸다. 이 스킬은 원장님 개인 업무(전화, 문자 발송,
결제, 구매/준비 등)만 다룬다. 한 문장에 둘 다 섞여 있으면 각자 맞는 스킬로 나눠 기록한다.

## 0. 시작하기 전에 항상 확인할 것

1. **이 세션에 Notion 연동이 되어 있는지 먼저 확인한다** (도구 목록에 `mcp__Notion__*` 계열이
   있는지). 없으면 "지금 이 창에는 Notion 연동이 안 되어 있어서 자동으로 저장은 못 하고,
   대화로만 도와드릴 수 있어요"라고 알리고 노션에 손으로 옮겨 적을 수 있게 문구만 정리해준다.
2. **날짜가 있는 일인지 없는 일인지 먼저 판단한다.** "9/7일부터", "화요일에", "내일", "이번 주
   토요일" 처럼 특정 날짜/요일이 언급되면 날짜 있는 일 → 2번(업무 캘린더). 그냥 "언젠가 해야
   할 일"이면 날짜 없는 일 → 1번(할일 TASKS 페이지).
3. **중복 확인**: 기록하기 전에 대상 페이지/데이터베이스를 먼저 읽어서, 같은 내용이 이미 있으면
   다시 추가하지 않는다 (완전히 같은 문구가 아니어도 같은 학생/같은 용건이면 중복으로 본다).
4. 기록한 뒤에는 항상 한 줄로 확인 메시지를 준다: 예) "할일(TASKS) → 전화할 것에 추가했어요:
   '수원외고 금액 확인'". 사용자가 카테고리/섹션이 잘못됐다고 하면 그 자리에서 옮긴다.

## 1. 날짜 없는 일 → "✅ 할일 (TASKS)" 페이지

- 페이지: `https://app.notion.com/p/39da9006a9ef8176bfe1c4686422c802` (id
  `39da9006-a9ef-8176-bfe1-c4686422c802`). 이 링크가 더 이상 안 열리면(페이지 이동/재생성)
  Notion에서 "학사 운영 허브" 페이지(`https://app.notion.com/p/3c0a9006a9ef814e98b8c88003593f88`)를
  열어 "할일 (TASKS)" 링크를 다시 찾는다.
- 페이지 안은 마크다운 체크박스 목록이고, 아래 섹션으로 나뉘어 있다 — **내용에 맞는 섹션 바로
  아래에 `- [ ] 할일 내용` 한 줄을 새로 추가**한다 (기존 줄은 절대 건드리지 않는다):
  - `## 오늘 할 일` — 사용자가 "오늘"이라고 명시했을 때만
  - `## 전화할 것` — 전화/통화 관련
  - `## 문자 발송할 것` — 문자/카톡 발송 관련
  - `## 구매/준비할 것` — 물건 구매, 준비물, 주문
  - `## 나중에 할일` — 위 어디에도 뚜렷이 안 맞는 일반적인 할일의 기본 위치 (급하지 않은 잡무)
  - `## 이월된 일 (어제 못 한 것)`, `## 완료` 는 자동 정리(아침 브리핑/밤 정리) 대상이니
    **새로 추가할 때 이 두 섹션에는 넣지 않는다.**
- 항목 문구는 원문 어투를 살려서 짧게 — 기존 항목들처럼 "학생이름 + 무엇을" 형태로 적는다
  (예: "박소진 샘 7~8월 같이 정산하기", "수원외고 금액 확인").

## 2. 날짜 있는 일 → "📅 업무 캘린더 (날짜별)" 데이터베이스

- 데이터베이스: `https://app.notion.com/p/a82a2e017256402793dc74e6347eba63`
  (data source `collection://d6cea88b-81b2-46c8-a040-fde5383f6686`). 마찬가지로 안 열리면
  학사 운영 허브 페이지에서 다시 찾는다.
- 새 행을 만들 때 속성:
  - `업무` (title) — 할일 내용, 짧게
  - `날짜` (date) — 언급된 날짜/요일을 실제 캘린더 날짜로 환산해서 넣는다 (오늘 날짜 기준으로
    "화요일", "다음 주" 등을 계산 — 절대 임의로 대충 넣지 않는다. 애매하면 사용자에게 날짜를
    확인한다)
  - `카테고리` (select, 다음 중 하나) — 아래 표로 판단:

    | 카테고리 | 판단 기준 |
    |---|---|
    | 결제/카드 | 결제, 카드, 입금, 환불, 결제링크 발송 |
    | 전화 | 전화, 통화 |
    | 문자 | 문자, 카톡, 안내문 발송 |
    | 구매/준비 | 구매, 주문, 준비, 챙기기 |
    | 일정 | 수업/시간표/강의실 변경·배정, 보강 등 운영 일정 |
    | 기타 | 위 어디에도 뚜렷이 안 맞을 때 |
  - `메모` (text) — 학생 연락처, 배경 설명 등 부가 정보가 있으면 여기에 (없으면 비워둠)
  - `완료` (checkbox) — 새로 만들 때는 항상 미완료(체크 안 함)로 시작

## 3. 하지 말아야 할 것

- 학원 운영과 무관한 개인적인 잡담·메모는 이 스킬 대상이 아니다 (억지로 노션에 적지 않는다).
- 노션 원본 서식(체크박스 마크다운, 데이터베이스 속성 타입)을 바꾸지 않는다 — 있는 구조에
  맞춰 새 항목만 추가한다.
- 애매한 항목을 마음대로 각색하지 않는다 — 짧게 정리하되 학생 이름·핵심 용건은 그대로 유지한다.
