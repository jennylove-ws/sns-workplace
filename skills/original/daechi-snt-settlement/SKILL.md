# 대치SNT학원 출석부 → 정산파일 작성 스킬

이 스킬은 학원 강사 출석 결과 엑셀(원본, 열-병합 없는 raw export)을 받아서, 대치SNT학원 표준 형식의
**정산 파일(반별 표 + 정산내역)**을 자동으로 만든다. 신영준T/엄형국T 파일 작업 과정에서 확립된 규칙을
그대로 따른다.

## 0. 시작하기 전에 항상 확인할 것

1. **선생님 이름과 반 이름**을 출석 결과 파일에서 확인한다 (A열 `학급명`).
2. `references/teacher_policy.md`에서 이 선생님이 이미 등록되어 있는지 확인한다.
   - 등록되어 있으면 그 정산 방식(기본50% / 60% / 중고등구분 / 합계만 / 시급제)을 그대로 적용한다.
   - **등록되어 있지 않은 새 선생님이면 절대 임의로 50%를 가정하지 말고, 어떤 방식인지 사용자에게 먼저 묻는다.** 확정되면 `teacher_policy.md`에 행을 추가해 기록한다.
   - **시급제로 등록된 선생님(2026-08-22 기준: 박소진T·박주신T·배수안T·백강현T·장현명T·전진선T)은 시급이 아직 미확정이다.** `references/policy_시급제.md` 참고 — 시급/계산식을 사용자가 알려주기 전까지는 정산 파일의 최종 지급액 계산을 진행하지 않는다.
3. **회당 단가(單價)** 는 출석 결과 파일에 없다. 다음 순서로 먼저 찾아보고, 그래도 없으면 그때
   사용자에게 확인한다 (임의로 추측해서 채우지 않는다):
   1) **Notion·Google Drive 연동이 이 세션에 되어 있으면 이게 최우선이다.** Notion의
      "🏫 학원 운영 본부 (Claude 조직도)" 페이지(`https://app.notion.com/p/3c0a9006a9ef814e98b8c88003593f88`)
      → "팀 1. 시간표·수강료팀장" 또는 "팀 2. 정산·회계팀장" 섹션에 링크된 최신
      "OO학기 수업 회차 & 수강료 (원본 문서)" 구글독스를 열어서 확인한다 (읽기 전용 — 이
      문서를 직접 고치지 않는다). 이 구글독스 한 파일 안에 회차·수강료뿐 아니라 강의실배정
      섹션도 같이 들어있다. 이 허브 페이지 자체가 매 학기 최신 링크로 갱신되므로, 개별
      구글독스 URL을 이 스킬 안에 하드코딩하지 않고 항상 허브 페이지를 거쳐 찾는다.
   2) 프로젝트에 첨부된 회차·수강료 문서가 있고 위 방법을 못 쓰는 상황이면 참고할 수는
      있지만, **2026-08-22 확인 결과 프로젝트에 첨부된 사본은 실제로 최신 구글독스와 반명·
      강의실 배정이 다른 경우가 있었다(예: 신영준T "유신/창현B" 반 누락, 일부 강의실 번호
      불일치).** 프로젝트 사본과 Notion 경유 원본이 다르면 **항상 Notion 경유 원본을
      따른다.** 프로젝트 파일이 이미 삭제됐다면 이 단계는 건너뛴다.
   3) 위 방법으로도 못 찾으면 사용자에게 단가를 확인한다.
4. 출결 코드 중 처음 보는 코드가 있으면(3번 규칙에 없는 코드) 임의로 판단하지 말고 사용자에게 의미를 묻는다.
5. 파일이 openpyxl로 바로 안 열리면(styles.xml 오류 등) 아래 "기술 노트"의 LibreOffice 복구 단계를 거친다.
6. **구글독스/구글시트 원본은 항상 읽기 전용으로만 다룬다.** 참고는 하되 셀·텍스트를 직접
   고치지 않는다 — 수정된 결과물은 항상 새 파일(정산 xlsx)로 만들어 사용자에게 전달한다.

## 1. 전체 파일 구조

- **반(과목)별로 표를 분리**한다 (병합하지 않고 표를 아래로 이어 붙임). 학급명이 다르면(예: 같은 "브릿지" 파일 안에 "2시"/"7시"처럼 실제로는 다른 학급명) 별도 표로 나눈다.
- 표 순서: 특별한 지시가 없으면 최근 반을 위에, 기존 표는 아래로.
- 표 제목은 `① [반 이름]`, `② [반 이름]` 처럼 원 번호.
- **표 제목 줄에 그 반의 학생 수·실입금액 합계를 수식으로 바로 표시**한다:
  `① [반 이름]  (총 N명 / 실입금액 합계 8,007,375원)` — TEXT()로 합계 셀을 이어붙인 수식.
- 맨 아래 전체 반을 합산하는 **【정산내역】** 섹션.

## 2. 표 컬럼 구성 (반별 공통, 병합 없음 — 1행=1학생, 1열=1항목)

| 컬럼 | 내용 |
|---|---|
| No. | `=ROW()-시작행` (하드코딩 금지) |
| 이름 | 신규/중도입학생은 `이름(신)` 표기 + 셀 메모(comment)에 "M/D(요일)\t수강시작" |
| 학교 | 아래 3번 참고 |
| 날짜별 출석 (여러 열) | 실제 수업일만큼만 열 생성. 출석=`1`, 미포함=빈칸(색상은 4번 참고) |
| 출석횟수 | `=COUNTA(날짜범위)` |
| 단가 | 사용자 확인값, **파란 글씨** (하드코딩 입력 표시) |
| 실수강료 | `=출석횟수*단가` |
| 납부방법 | 기본 "카드" |
| 실입금액 | `=IF(납부방법="카드",0.978*실수강료,실수강료)` |

데이터 행은 **절대 병합하지 않는다** (필터/정렬/수식 참조를 위해). 병합은 "합계"·"정산내역"처럼 라벨+숫자 하나만 보여주는 요약 행에서만 허용된다.

## 3. 학교 정보 처리 (연락처 대신 학교 사용)

- 원본에는 보통 전화번호만 있고 학교가 없다. **개인정보 보호 + 확인 목적**을 고려해 학교 컬럼을 쓴다(연락처는 안 씀).
- 학생 이름으로 `assets/student_roster.xlsx`(학생 명부)를 먼저 찾아본다. 있으면 그 학교로 자동 채운다.
- 명부에 없으면: 동일 학생이 이미 처리한 다른 T 파일에 있는지(이번 세션에서 만든 다른 표) 확인 후 있으면 채운다.
- 그래도 없고 Notion·Google Drive 연동이 되어 있으면: Notion "🏫 학원 운영 본부 (Claude 조직도)"
  페이지 → "팀 2. 정산·회계팀장" 섹션의 "학생 명부(최신)" 구글시트를 열어서 찾아본다 (읽기 전용).
- 그래도 없으면 **노란색 배경**으로 비워두고 사용자에게 확인 요청.
- **새로 확인된 학교 정보는 반드시 `assets/student_roster.xlsx`에도 행을 추가해 누적한다.** (다음 작업에서 재사용)
- 동명이인 가능성이 있으면(확신이 안 서면) 채우지 않고 확인 요청한다.

## 4. 출결 코드 → 회차 산정 규칙 (고정)

| 코드 | 회차 포함 | 비고 |
|---|---|---|
| 출 / 지 / 통결 / 결석 / 결 | ✅ 포함 | 전부 영상보강 진행 전제 |
| 출(시작) / 결(시작) / 출(신규) | ✅ 포함 (그 날짜부터) | 이름에 `(신)` 붙이고 셀 메모로 "M/D 수강시작" 남김 |
| 미 | ❌ 미포함, **노란색** | 출결 미확인 — 나중에 확인 필요 |
| 전반 / 휴원 / 퇴원 / 영상보강 없음 | ❌ 미포함, **연한 블루** | 등록 전/일시정지/중도퇴원/보강없음 |
| 처음 보는 코드 | — | 임의 판단 금지, 사용자에게 의미 확인 |

- 위 규칙에 없어 그냥 빈 칸으로 남는 날짜(등록 전 등)도 **연한 블루**로 채운다.
- 목요일 클리닉처럼 "이 요일은 아예 회차 대상이 아님"이라는 지시를 받으면, 그 요일 날짜 **열 자체를 표에서 제거**한다 (빈 칸으로 두지 않음).

## 5. 정산내역 계산 — 선생님 방식별 (자세한 수식은 references/ 참고)

먼저 `references/teacher_policy.md`에서 이 선생님의 방식을 확인한 뒤 해당 문서를 연다:

| 방식 | 문서 | 핵심 공식 |
|---|---|---|
| 기본 | `references/policy_기본.md` | ②=ROUNDUP(①×50%,-1) |
| 60% | `references/policy_60퍼센트.md` | ②=ROUNDUP(①×60%,-1) |
| 중고등구분 | `references/policy_중고등구분.md` | 반별로 학생 구분(고등50%/중등40%)에 따라 자동계산 후 합산 |
| 합계만 | `references/policy_합계만.md` | 비율 단계 없이 ①에서 바로 세금 공제 |
| 시급제 | `references/policy_시급제.md` | **기준 미확정 (2026-08-22).** 시급/계산식이 확정되기 전까지 진행하지 않는다 |

세금(사업소득세 3.0%, 지방소득세 0.3%, `-1`자리 절사)은 **시급제를 제외한 네 방식 모두 공통**이며 방식과 무관하게 항상 적용한다. 시급제는 세금 공제 여부 자체가 아직 확인되지 않았다.

중고등구분 방식은 **반 이름이 아니라 학생 개별 학교명**으로 판정한다 (판정 순서는 `references/policy_중고등구분.md` 2번 참고). "예비고1" 반은 실제로 중3 학생 반이므로 중등(40%)으로 취급한다.

## 6. 레이아웃/가독성 원칙 (스크롤 없이 한눈에)

- 반별 표가 날짜 열이 많아 옆으로 길어질 수 있으므로:
  - 각 반 표 **제목 줄에 실입금액 합계를 수식으로 표시** (1번 참고).
  - **【정산내역】은 표 전체 너비에 맞추지 않고 왼쪽(예: A~F열 라벨, G~K열 금액)에 좁게 배치** — 표가 아무리 넓어져도 정산내역은 스크롤 없이 보이게.
  - **No./이름/학교 열은 틀 고정(freeze_panes)** 해서 날짜 열이 많아도 이름·학교가 계속 보이게.

## 7. 스타일 규칙

- 폰트: 나눔바른고딕 Light(본문) / 굵게(헤더·합계·지급액)
- 하드코딩 입력값(단가): **파란 글씨**
- 학교 미확인: **노란색 배경**
- 미확인('미') 날짜: **노란색 배경**
- 회차 미포함(전반/휴원/퇴원/등록전 등): **연한 블루 배경** (권장 hex `DDEBF7`)
- 헤더 행: 회색 배경 + 굵게
- 합계/요약 행: 연한 회색 배경 + 굵게
- 금액 표시: `₩#,##0` (음수는 빨간 괄호)

## 8. 작업 순서 (체크리스트)

1. 출석 결과 파일에서 반 이름/학생 명단/날짜별 출결 코드 확인.
2. `references/teacher_policy.md`에서 방식 확인 (없으면 확인 요청 + 기록).
3. 단가 확인 (임의 가정 금지).
4. 처음 보는 출결 코드 있으면 의미 확인.
5. 출결 코드를 4번 규칙대로 1/빈칸(색상 포함)으로 변환.
6. 반별 표 작성 (병합 없이 1행=1학생), 기존 표 아래(또는 지시대로 위)에 이어 붙임.
7. 학교 정보: `assets/student_roster.xlsx` → 다른 표 → 없으면 노란색.
8. 정산내역 섹션을 선생님 방식에 맞는 공식으로 연결, 왼쪽 압축 배치.
9. 모든 값은 수식으로 (하드코딩 금지).
10. LibreOffice로 재계산해 수식 오류 없는지 확인 후 전달 (기술 노트 참고).
11. 새로 확인된 학교 정보는 `assets/student_roster.xlsx`에 추가.

## 기술 노트 (파일 처리)

- **원본 출석부/과거 정산파일이 openpyxl로 안 열리는 경우** (styles.xml `IndexError` 등): 먼저 LibreOffice로 변환해 복구한다.
  ```bash
  python3 /mnt/skills/public/xlsx/scripts/office/soffice.py --headless --convert-to xlsx --outdir repaired <원본파일>.xlsx
  ```
- **정산 파일을 새로 만들 때는 openpyxl로 직접 작성**한다 (병합 셀, 서식, 수식 문자열 조합). `scripts/build_settlement.py`에 재사용 가능한 헬퍼 함수(`build_table`)가 있으니 참고해서 이름/학교/단가/출결만 바꿔 재사용한다.
- **저장 후 반드시 재계산**해서 수식 값이 채워지고 오류가 없는지 확인한다:
  ```bash
  python3 /mnt/skills/public/xlsx/scripts/recalc.py <파일>.xlsx 90
  ```
  `total_errors`가 0인지 확인. 결과의 `data_only=True` 로드로 핵심 셀 값을 검산(예: 반별 합계 손계산과 비교)한 뒤 전달한다.
- 필요하면 PDF로 변환해 레이아웃을 시각적으로 확인할 수 있다:
  ```bash
  python3 /mnt/skills/public/xlsx/scripts/office/soffice.py --headless --convert-to pdf <파일>.xlsx
  ```
