# 정산 방식: 합계만 (비율 없음)

공통 규칙(표 구조·출결 코드·학교 처리·레이아웃·스타일)은 `SKILL.md`를 따르고, 여기서는 정산내역 계산 공식만 정의한다.

> 선생님이 실입금액 전액을 가져가고, 사업소득세·지방소득세만 실입금액 합계(①)에서 바로 공제한다. "비율" 단계 자체를 만들지 않는다 (기본 방식처럼 비율 행을 만들어뒀다가 나중에 세금만 계산하는 실수를 방지하기 위해, 애초에 정산내역 표에 비율 항목을 넣지 않는다).

```
① 실입금액              = 모든 반 표의 "실입금액 합계"를 더한 값
② ①의 사업소득세 3.0%   = ROUNDDOWN(① * 3%, -1)
③ ①의 지방소득세 0.3%   = ROUNDDOWN(① * 0.3%, -1)
지급액 (①-②-③)         = ① - ② - ③
```

- 사업소득세·지방소득세 둘 다 반드시 `-1`로 통일한다 (엄태욱T 사례: 하나만 `0`으로 잘못 입력되는 실수가 실제로 있었으니 새 파일 작성/검수 시 꼭 확인).

적용 대상: 엄태욱T, 현민논술.
