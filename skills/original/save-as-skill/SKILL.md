# 작업을 스킬로 저장하기

## 원칙 (2026-09-29 사용자 결정)
- **모든 스킬의 원본은 claude.ai 계정 한 곳이다.** 그래야 채팅·데스크톱 앱·Claude Code가 같은 스킬을 본다.
  로컬 `~/.claude/skills/`나 프로젝트 `.claude/skills/`에 따로 설치하지 않는다(같은 스킬이 두 벌 생겨 내용이 어긋난다).
- **작업이 끝난 뒤에 저장한다.** 작업 중간이 아니라, 실제로 해 보고 확인된 절차·함정·결정을 담는다.
- **저장한 내용을 사용자에게 보여준다.** 무엇이 새로 들어갔고 무엇이 바뀌었는지 짧게 요약한다.

## 절차
1. **새 스킬인지, 기존 스킬 수정인지 판단한다.** 비슷한 스킬이 이미 있으면(스킬 목록에 `anthropic-skills:` 접두사로 보이는 것 포함) 새로 만들지 말고 그 스킬을 고친다. 기존 스킬을 고칠 때는 현재 내용을 먼저 읽는다. **규칙이 바뀌면 옛 규칙은 지우고 새 규칙만 남긴다** — "9/22엔 A → 9/23에 B로 원복" 같은 변경 이력을 쌓지 않는다(어느 게 지금 규칙인지 헷갈린다). 같은 실수를 막아 주는 이유만 한 줄 남긴다(예: "👇 이모지를 넣으면 문장이 사라짐 → 넣지 않는다"). 이번 수정과 관계없는 다른 규칙은 건드리지 않는다.
2. **SKILL.md를 쓴다.**
   - 맨 위 frontmatter: `name`(영문 소문자·하이픈, 기존 스킬을 고치면 이름을 바꾸지 않는다), `description`(언제 이 스킬을 써야 하는지 — 사용자가 실제로 할 법한 말을 넣어 잘 불리게).
   - 본문: 무엇을·어떤 순서로·왜. 지금 유효한 규칙만 적고, 실제로 겪은 함정은 이유 한 줄과 함께 적는다. 경로·ID 같은 구체적 값은 그대로 적는다.
   - 스크립트·참고 문서가 필요하면 같은 폴더에 넣는다(`scripts/`, `references/`).
3. **환경에 맞게 전달한다.**
   - **claude.ai 채팅**: 스킬 폴더를 `.skill` 파일(= 폴더를 통째로 담은 zip)로 만들어 전달한다 — 채팅 화면에 스킬 저장/업로드 버튼이 뜬다. 버튼이 안 뜨면 파일을 내려받아 설정 → 기능 → 스킬에서 올리라고 안내한다.
   - **데스크톱 앱 코드 탭 / 웹 Claude Code / 터미널**: `<스킬이름>.zip`을 만든다. zip 안의 최상위는 스킬 폴더 하나여야 한다(`<스킬이름>/SKILL.md`). 데스크톱이면 `C:\Users\koyon\OneDrive\바탕 화면\웹 업로드용 스킬\`에 저장하고 파일로 보내 준다. 올리는 곳: claude.ai → 설정 → 기능(Capabilities) → 스킬 → 업로드. **기존 스킬 수정이면 claude.ai에서 예전 것을 지우고(또는 교체) 새 zip을 올리라고** 알려 준다.
4. **보여주기**: 스킬 이름, 새 스킬인지 수정인지, 추가·변경된 핵심 내용 3~5줄, 파일 위치.

## 하지 말 것
- 사용자가 올리기 전인데 "저장 완료"라고 말하지 않는다 — "올릴 파일을 만들었다"고 말한다.
- 비밀번호·API 키·토큰 같은 값을 스킬에 넣지 않는다(`.env` 같은 위치만 적는다).
- 한 번 쓰고 말 내용(오늘 날짜의 할 일 목록 등)은 스킬에 넣지 않는다. 반복될 절차와 규칙만.
