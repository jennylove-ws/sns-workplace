# 대치SNT학원 문자/안내문 작성 스킬

이 스킬은 대치SNT학원에서 실제로 써온 6가지 문자/안내문 양식(`references/templates.md`)을 기준으로,
선생님·학부모·학생에게 보낼 문구를 만든다. 문구 자체의 어투·구조는 원본 그대로 따르고,
반명/요일/시간/회차/수강료/강의실 같은 "숫자·사실 데이터"만 최신 값으로 채워 넣는다.

## 0. 시작하기 전에 항상 확인할 것

1. **어떤 양식인지 먼저 판단한다** (아래 6종 중 하나):
   - 선생님 회차확인 문자 / 학부모 수강료 안내 문자 / 학생·학부모 강의실 안내 문자 /
     선생님 강의실 확인 문자 / 미납 안내 문자 / 선생님 상담요청 문구(예시 참고용)
   - 애매하면 사용자에게 "어떤 용도의 문자인가요?"라고 먼저 묻는다.
2. **회차·날짜·수강료·강의실 숫자를 절대 새로 계산하지 않는다.** 이미 tuition-schedule 스킬로
   만들어둔 `data/classes.json`, `gen_dates.py` 실행 결과, 강의실배정 문서에서 그대로 가져온다.
   해당 데이터가 없거나 이번 학기 것으로 아직 안 만들어졌으면, 먼저 tuition-schedule 스킬로
   회차·강의실을 확정한 뒤 이 스킬로 넘어오거나, 사용자에게 반별 정보를 직접 물어본다.
3. **학원명 태그는 항상 "대치SNT"로 고정한다** (사용자가 다른 이름을 지시하지 않는 한).
4. **계좌번호, 미납 학생 이름/미납일자, 상담 요청 내용처럼 사람만 아는 정보는 절대 지어내지 않는다.**
   빈칸으로 남겨두거나(예: "계좌 입금 : ") 사용자에게 먼저 확인한다.
5. 문자는 보통 반별·선생님별로 여러 건을 한 번에 요청받는다 — 아래 3번 규칙대로 정리해서 출력한다.

## 1. 공통 헤더/톤

- **학부모·학생 대상**: "안녕하세요, [대치SNT] 학원입니다."로 시작.
- **재원생 대상 강의실 안내**는 맨 위에 "★★ 재원생 필독 ★★"을 추가한다.
- **선생님 대상**은 "안녕하세요 OOO 선생님," 또는 "선생님,"으로 시작하고 끝까지 존댓말을 유지한다.
- 맺음말은 문구 성격에 맞춰 원본 톤을 그대로 따른다: 강의실 안내는 "꼭 확인하시어 수강에
  차질 없길 바랍니다.", 미납 안내는 "확인 후 납부 부탁드립니다" + "감사합니다 :)", 선생님
  안내는 "해당 강의실 사용해주시면 됩니다. 감사합니다!" 등.
- 반/수업 표기는 tuition-schedule 스킬과 동일한 표기법을 따른다: `[학년]_반명 (과목) (OOOT) –
  요일/시간 [회당 단가 또는 1개월 정액]`, 날짜 줄은 `- 8/2, 9, 16 (총 N강, 총액)`.

## 2. 양식별 요약 (자세한 원문은 `references/templates.md` 참고)

| 양식 | 대상 | 데이터 출처 |
|---|---|---|
| 회차확인 문자 | 선생님 | classes.json / gen_dates.py 결과 (그 선생님 담당 반 전체) |
| 수강료 안내 문자 | 학부모·학생 | 위와 동일 + 결제방법/주의사항 공통 블록 |
| 강의실 안내 문자 | 학생·학부모 (재원생) | classes.json + 강의실배정 문서 |
| 강의실 확인 문자 | 선생님 | 강의실배정 문서 (해당 선생님 담당 반 전체를 한 메시지로 묶음) |
| 미납 안내 문자 | 특정 학생 1인 | 사용자가 알려주는 미납 정보 (자동 산출 불가) |
| 상담요청 문구 | 선생님 | 사용자가 알려주는 상황 설명 (예시 톤만 참고, 내용은 그때그때 새로 작성) |

## 3. 여러 건을 한 번에 요청받았을 때 정리 방식

- **선생님 강의실 확인 문자**처럼 한 선생님이 여러 반을 담당하면: 선생님 한 명당 메시지 하나로
  묶고, 그 안에서 반을 줄바꿈으로 나열한다 (`references/templates.md`의 "강의실 확인_선생님"
  예시 참고).
- **강의실 안내 문자**(학생·학부모용)처럼 반마다 별도 발송이 필요한 경우: 반 하나당 메시지
  하나를 만들고, 여러 반/여러 선생님을 한 번에 요청받으면 반 사이는 `----`, 선생님(발송
  묶음) 사이는 `====`로 구분해 순서대로 나열한다.
- 몇 건을 만들든, 각 메시지 위에 "① [고2]_유신/창현A (신영준T)" 식으로 어떤 반/선생님 것인지
  라벨을 붙여서 사용자가 대상별로 바로 구분해 복사할 수 있게 한다.

## 4. 작업 순서 (체크리스트)

1. 어떤 양식인지, 누구 대상인지 확인한다.
2. 필요한 반/회차/수강료/강의실 데이터를 classes.json이나 관련 문서에서 가져온다. 없으면
   tuition-schedule 스킬을 먼저 실행하거나 사용자에게 확인한다.
3. 계좌번호·미납정보·상담 내용처럼 사람만 아는 정보는 사용자에게 확인한다 (지어내지 않는다).
4. `references/templates.md`의 해당 양식에 맞춰 문구를 작성한다. 반별/선생님별 정리 규칙(3번)을
   적용한다.
5. 전달하기 전 반명·요일·시간·회차·금액 숫자가 원본 데이터와 일치하는지 검산한다.
