**정본(가장 최신)은 Notion "💬 문자양식 라이브러리" 페이지**
(`https://app.notion.com/p/39ca9006a9ef8104830dcb8ab3b2669c`, 안 열리면 "🏫 학원 운영 본부"
허브에서 다시 찾는다)이고, 그 페이지는 구글독스 "학부모_안내문_강의실안내_문자양식(최신)"을
그대로 옮겨 적은 것이다. 2026-08-22에 대조해보니 이 프로젝트에 첨부됐던
`대치SNT_문자양식.docx`(2026-07-02 작성)는 **결제방법·문의처 문구가 구식이라 그대로 쓰면 안
된다** — 아래 1, 2, 3, 5, 6번은 Notion 정본 기준으로 갱신했다. Notion·Google Drive 연동이
되어 있으면 문자를 쓰기 전에 항상 이 Notion 페이지를 먼저 열어서 그새 바뀐 내용이 없는지
확인한다(특히 결제방법 블록, 문의 번호, 카카오 채널 링크는 자주 바뀔 수 있는 정보다).
**4번(선생님 강의실 확인 문자)만 Notion 라이브러리에 없는 항목**이고, 프로젝트에 있던
`대치SNT_강의실 확인_선생님.docx` 원본에서 가져왔다 — 이것도 원본 문서가 없어져도 괜찮도록
아래에 그대로 채록해뒀다.

`{{ }}`는 채워 넣을 자리, `[...]`는 원문에 실제로 들어가는 대괄호 표기(학년, 반명, 학원 태그
등) — 둘을 혼동하지 않는다.

## 1. 선생님 회차확인 문자

선생님에게 "이번 달 회차/수강료 이렇게 계산했는데 맞는지 확인해달라"고 보내는 문자. 여러 반을
담당하면 반마다 블록을 이어붙인다.

```
선생님, {{월}}월 수업 회차 및 수강료 확인 부탁드리겠습니다,

[{{학년}}]_{{반명}} ({{과목}}) ({{선생님}}T) – {{요일/시간}} [{{단가/정액}}]
- {{월}}/{{날짜1, 날짜2, ...}} (총 {{N}}강, {{총액 또는 "1개월 정액"}})

[다른 반이 더 있으면 같은 형식으로 아래에 이어붙인다]
```

정액제 반은 "총 8강, 1개월 400,000원"처럼 정액임을 표시한다 (회차 수는 참고용, 금액은 곱하지 않음).

## 2. 학부모 수강료 안내 문자

학부모에게 이번 달 수강료를 청구하는 문자. 결제방법·주의사항 블록은 거의 고정 문구다.

```
안녕하세요, [대치SNT] 학원입니다.

{{월}}월 수강 회차 및 수강료 안내드립니다.

[{{학년}}]_{{반명}} ({{과목}}) ({{선생님}}T) – {{요일/시간}} [{{단가/정액}}]
- {{월}}/{{날짜1, 날짜2, ...}} (총 {{N}}강, {{총액}})

■ 수강료 결제방법
- 카카오톡 올톡페이 결제
- 방문 카드결제
- 계좌입금이나 현금결제를 원하시는 경우 031-895-5003으로 전화 부탁드립니다.

■ 주의사항
- 계좌 이체 시 학생 이름/학교/학년으로 이체 해주셔야 확인 가능하며, 만약 다른 이름으로 입금
  주셨을 경우 확인이 불가하니 입금자명을 알려주시면 감사하겠습니다.

※ 학원 안내 및 문의처
- 문의 번호: 031-895-5003

※ [필수] 카카오톡 채널 추가 및 학생 이름 전송 요청
채널 추가 후 [학생 이름]을 메시지로 한 번만 남겨주시면 감사하겠습니다.
- 카카오 채널 추가 링크: https://pf.kakao.com/_ijRXX
```

결제방법 문구, 문의 번호, 카카오 채널 링크는 시기별로 바뀔 수 있으므로, 위 텍스트를 고정
값으로 암기하지 말고 항상 Notion "문자양식 라이브러리" 페이지에서 최신 문구를 확인한다.
보강/직보 등으로 회차가 바뀐 경우 원본처럼 날짜 옆에 "(직보)" 같은 표시를 남긴다.

## 3. 학생·학부모 강의실 안내 문자 (개별 반용)

특정 학기/기간의 수업일정과 강의실을 재원생에게 공지하는 문자. 반 하나당 메시지 하나가 기본형.

```

안녕하세요, [대치SNT] 학원입니다.

■ [{{학년}}]_{{반명}} ({{과목}}) ({{선생님}}T)
-수업일정 : {{기간}} (총 {{N}}강)
-수업시간 : {{요일/시간}}
-강의실 : 3층 A관 {{강의실}}

{{월}}월 수업일정 및 강의실 안내드립니다.
꼭 확인하시어 수강에 차질 없길 바랍니다.
```

## 4. 선생님 강의실 확인 문자

선생님 본인에게 "이번 기간 이 강의실 쓰시면 됩니다"라고 알리는 문자. 학부모용(3번)보다 훨씬
간결하고, 한 선생님의 담당 반 전체를 메시지 하나에 모은다.

```
### {{번호}}. {{선생님}}T

안녕하세요 {{선생님}} 선생님, {{기간 설명 — 예: 프리썸머 기간(07.06-07.19)}} 강의실 안내드립니다.

 [{{학년}}] {{반명}} ({{과목이 필요하면}}) ㅣ A관 {{강의실}}
 [{{학년}}] {{반명2}} ({{과목}}) ㅣ A관 {{강의실2}}
 [클리닉이 별도 강의실이면 "(요일)클리닉 A관 N강의실" 형식으로 같은 줄에 덧붙인다]

해당 강의실 사용해주시면 됩니다. 감사합니다!
--------------------------------------------------------------------------------
[다음 선생님 — {{번호}}. {{선생님}}T 부터 반복]
```

## 5. 미납 안내 문자

특정 학생 1인에게 보내는 미납 독촉 문자. **회차·수강료·강의실 데이터로 자동 산출할 수 없다** —
학생 이름과 미납 확인일자를 반드시 사용자에게 먼저 확인한다.

```
[{{이름}}]학생 {{월}}월 수강료 미납 안내 문자 (제목)

안녕하세요, [대치SNT] 학원입니다.

[{{이름}}]학생 {{월}}월-{{일}}일자로 미납으로 확인되어 연락드렸습니다.

확인 후 납부 부탁드립니다

감사합니다 :)
```

## 6. 선생님 상담요청 문구 (예시 참고용 — 매번 새로 작성)

신규/재원 학생 상담 요청을 선생님에게 전달하는 문구. 상황(학생 학교/학년, 문의 내용, 연락처,
회신 기한)이 매번 다르므로 **자동 생성 대상이 아니다** — 아래는 톤/구조만 참고하고, 실제 내용은
사용자가 알려주는 상황에 맞춰 새로 쓴다.

```
선생님 안녕하세요,

신규로 {{학교}}{{학년}} {{학생 익명 표기 — 예: OOO}}학생 어머님께서 전화 상담 요청하셨습니다.
{{상담 요청 배경/문의 내용을 1~2문장으로}}

{{회신 기한 — 예: 오늘 안으로}} 전화 상담 부탁드린다고 말씀해주셨습니다.
M. {{연락처}}
```

정해진 양식이 없으므로, 위 6종 어디에도 억지로 끼워맞추지 말고 사용자가 요청하는 내용 그대로
정중한 톤으로 새로 작성한다.
