# 대치SNT학원 SNS·마케팅 콘텐츠 스킬

Jenny님이 주제나 상황(예: "중등 설명회 홍보글", "이번에 입시결과 나온 거 홍보", "S반 소수정예 강조해서 인스타 올릴 것")을 주면, 그 상황에 맞는 강조 포인트·타겟·톤을 판단해서 요청한 채널(들)의 콘텐츠 초안을 만든다. 여러 채널을 한 번에 요청하면 채널마다 순서대로 만든다.

**주의 — daechi-snt-messaging 스킬과 용도가 다르다.** 회차확인, 수강료 안내, 강의실 안내, 미납 안내처럼 재원생 대상 운영성 안내는 daechi-snt-messaging 스킬을 쓴다. 이 스킬은 신규 모집·설명회·입시결과·강사진 홍보처럼 **대외 홍보/마케팅** 콘텐츠 전용이다. "학부모 발송용 문자"라도 홍보성(설명회 안내, 신규 모집 안내 등)이면 이 스킬, 이미 등록한 학생의 수강료/회차 안내면 daechi-snt-messaging이다 — 헷갈리면 사용자에게 확인한다.

## 0. 시작하기 전에 판단할 것 (3가지)

콘텐츠를 쓰기 전에 아래 3가지를 먼저 정한다. 사용자 요청에 이미 답이 나와 있으면 다시 묻지 않고, **애매하면 짧게 1번만 확인 질문**을 하고 (한 번에 3개 다 물어봐도 됨) 넘어간다 — 잘못된 강조점/타겟으로 초안을 만들면 다시 써야 하니, 잘 모르겠으면 반드시 먼저 확인한다.

1. **어떤 상황/목적인가** — 예: 중등 설명회, 고등 설명회, 특목고반(외고/국제고/과학고 등) 홍보, 재원생 간담회 안내, 입시결과 홍보, 신규 강사/커리큘럼 홍보, 시즌 모집(겨울방학 특강 등). `references/brand_info.md`의 "상황별 시나리오" 표를 참고.
2. **어떤 강점을 강조할까** — 대치SNT는 상황마다 강조점이 다르다 (`references/brand_info.md`의 "강점 매핑" 참고):
   - 소수정예/밀착관리 반(예: S반) 홍보 → **소수정예·밀착관리** 강조
   - 특정 유명 강사 수업 홍보 → **강사진 실적/이력** 강조
   - 학원 전체/입시 시즌 홍보 → **입시 결과** 강조
   - 특정 과목/반의 교재·수업방식이 강점이면 → **커리큘럼/교재** 강조
   - 하나로 안 정해지면 사용자에게 "이번 건 뭘 제일 앞세울까요?"라고 물어본다 (추측해서 엉뚱한 강점을 앞세우지 않는다).
3. **타겟이 누구인가** — 중등 학부모, 고등 학부모, 특목고 지망 학부모, 재원생(기존 학부모), 또는 일반(잠재 고객) 중 어디인지. 상황에서 보통 자동으로 정해진다 (예: "중등 설명회" → 중등 학부모).

## 1. 채널별로 만들기

사용자가 채널을 지정하면 그것만, "SNS에 다 올릴 것"처럼 포괄적으로 말하면 관련된 채널(보통 블로그+맘카페+인스타) 전부를 만든다. 각 채널의 정확한 포맷/톤/예시는 `references/templates.md`에 있다 — 항상 그 파일을 참고해서 포맷을 지킨다.

| 채널 | 톤 (기본값, 상황에 따라 조정) | 핵심 |
|---|---|---|
| 블로그 (네이버 블로그) | 신뢰감 있고 정보 중심, 데이터/실적 근거 제시 | 제목 후킹 → 공감 도입 → 근거+강점 본문 → CTA → 해시태그 |
| 맘카페 | 친근한 구어체, 광고 느낌 최소화(후기/정보 공유하듯) | 과장 광고 문구 지양, 실제 학부모가 쓴 것처럼 자연스럽게 |
| 인스타그램 | 짧고 임팩트 있게, 트렌디 | 캡션 + 해시태그 블록 + 카드뉴스용 이미지 문구 제안 |
| 유튜브 | 숏폼은 캐주얼/훅 중심, 롱폼(설명회 다시보기 등)은 정보 중심 | 대본(숏폼) 또는 챕터 아웃라인(롱폼) |
| 학부모 발송 홍보 문자 | 격식 있는 안내문투 (daechi-snt-messaging과 동일한 브랜드 태그·문의처 규칙 사용) | `[대치SNT]` 태그, 문의처/카카오채널 블록 포함 |

숫자(입시 결과, 정원, 가격 등)는 이 스킬이 지어내지 않는다 — 사용자가 준 숫자만 쓰고, 없으면 "몇 명/몇 %인지 알려주시면 그대로 넣을게요"라고 물어본다.

## 2. 마케팅 전략 짜기

"마케팅 전략 짜줘", "이번 시즌 어떻게 홍보할까" 같은 요청이면 콘텐츠 초안 대신(또는 같이) 아래 구조로 전략을 짠다:

1. **목표** — 무엇을 위한 홍보인지 (신규 모집 / 설명회 참석 유도 / 브랜드 인지도 / 재원생 유지)
2. **타겟** — 위 0-3번 기준으로 정리
3. **핵심 메시지 (강조점)** — 위 0-2번 기준으로 정리, 상황에 안 맞으면 여러 개 조합 가능
4. **채널믹스 & 타이밍** — 어떤 채널을 언제(설명회 전/중/후) 쓸지, 채널별 우선순위
5. **콘텐츠 캘린더 제안** — 표 형식으로 날짜/채널/콘텐츠 주제 (일정이 정해져 있으면 daechi-snt-tasks 스킬의 업무 캘린더에도 등록할지 물어본다)
6. **CTA/전환 유도** — 설명회 신청, 카카오 채널 추가, 전화 문의 등 어디로 유도할지

## 3. 공통 규칙

- 완성된 콘텐츠를 줄 때는 채널마다 구분선(`---`)으로 나눠서, 어디부터 어디까지가 어떤 채널용인지 명확히 표시한다.
- 브랜드 표기는 `[대치SNT]` (성빈 등 다른 이름 쓰지 않는다), 문의처는 031-895-5003, 카카오 채널 링크는 `https://pf.kakao.com/_ijRXX` — 최신 정보는 daechi-snt-messaging 스킬의 `references/templates.md`와 Notion "문자양식 라이브러리"를 참고해서 바뀐 게 없는지 확인한다.
- 초안을 준 뒤에는 "이대로 쓰셔도 되고, 톤/강조점 다르게 원하시면 말씀해주세요" 정도로 한 줄 덧붙인다 — 광고 콘텐츠는 사람이 최종 검수하는 게 맞으므로 "바로 게시했다"는 식으로 말하지 않는다 (이 스킬은 초안 작성까지만 하고, 실제 게시는 사용자가 한다).
- 이 스킬은 초안만 만든다 — 실제로 블로그/인스타/유튜브에 게시하는 기능은 없다 (연동된 게시 도구가 없으면).
