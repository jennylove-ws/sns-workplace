# 대치SNT학원 결석·휴강·공식일정 → 구글 캘린더 자동 기록 스킬

Jenny님이 대화 중에 학생 결석, 선생님 휴강/보강, 학원 공식 일정을 언급하면 즉시 구글 캘린더에
기록한다. 명시적으로 "캘린더에 넣어줘"라고 하지 않아도, 결석·휴강·보강·공식 일정처럼 행정팀이
같이 알아야 하는 사실이 나오면 먼저 물어보지 말고 바로 기록하고, 기록한 뒤 한 줄로 확인해준다.

## 0. 시작하기 전에 항상 확인할 것

1. **이 세션에 Google Calendar 연동이 되어 있는지 먼저 확인한다** (`mcp__Google_Calendar__*`
   도구가 있는지). 없으면 "지금 이 창에는 Google Calendar 연동이 안 되어 있어서 자동으로
   등록은 못 하고, 대화로만 도와드릴 수 있어요"라고 알린다.
2. **대상 캘린더는 항상 사용자의 기본 캘린더(`ggyo.ganga@gmail.com`)다** — 2026-08-22에 Jenny님이
   직접 "행정팀과 공유하는 학원 공식 일정 캘린더가 맞다"고 확인했다. 새 캘린더를 만들지 않고,
   `list_calendars`로 다른 캘린더가 보여도 이 캘린더를 기본으로 쓴다.
3. **이 스킬과 daechi-snt-tasks 스킬은 용도가 다르다 — 혼동하지 않는다:**
   - 학생 결석 / 선생님 휴강·보강 / 학원 공식 일정(설명회, 방학, 시험기간, 개강·휴원) →
     **이 스킬** (구글 캘린더, 행정팀과 공유).
   - 원장님 개인 업무(전화, 문자 발송, 결제, 구매/준비 등 처리해야 할 일) →
     **daechi-snt-tasks 스킬** (Notion 할일/업무캘린더, 원장님 전용).
   - 한 문장에 둘 다 섞여 있으면(예: "OO 학생 결석 확인했고, 어머니께 전화하기") 결석 사실은
     이 스킬로 캘린더에, "전화하기"라는 할일은 daechi-snt-tasks로 Notion에 각각 나눠 기록한다.
4. **날짜/요일은 절대 암산하지 않는다.** 오늘 날짜를 기준으로 언급된 요일·상대 날짜("다음 주
   화요일", "이번 주 토요일")를 정확히 환산한다. 애매하면 사용자에게 날짜를 확인한다.
5. **등록 전에 같은 날짜 근처 이벤트를 먼저 조회해서 중복이면 다시 만들지 않는다.**
6. 기록한 뒤에는 항상 한 줄로 확인 메시지를 준다: 예) "구글 캘린더에 등록했어요: [결석]
   김민제 (신영준T 화목반) — 8/25". 잘못됐다고 하면 그 자리에서 삭제/수정한다.

## 1. 이벤트 종류별 작성 규칙

| 종류 | 제목 형식 | 시간 |
|---|---|---|
| 학생 결석 | `[결석] 학생이름 (반명/선생님T)` | 종일(allDay) 이벤트. 사유를 들었으면 description에 |
| 선생님 휴강 | `[휴강] 선생님T 반명 — 사유` | 원래 수업 시간대로 (시간 모르면 종일) |
| 보강 | `[보강] 학생/반명 — 원래 수업일 → 보강일` | 실제 보강 일시로 |
| 학원 공식 일정 | 일정명 그대로 (예: "중3 설명회", "추석 휴원") | 하루짜리면 종일, 기간이 있으면 시작~종료 |

- 결석/휴강/보강은 관련된 선생님·반명을 제목에 포함해서, 캘린더만 봐도 누구 관련인지 바로
  알 수 있게 한다.
- 참석자(attendees) 초대는 하지 않는다 — 그냥 캘린더에 기록만 한다. 사용자가 명시적으로
  누구를 초대해달라고 하면 그때만 추가한다.
- 설명(description)에는 원본 대화에서 나온 배경 정보(사유, 연락처 등)를 간단히 남긴다.

## 2. tuition-schedule / daechi-snt-tasks 스킬과의 관계

- 회차·수강료·강의실 배정 자체를 바꾸는 일(반 전체 일정 변경)은 tuition-schedule 스킬이
  담당한다 — 이 스킬은 그 결과로 생기는 "이 날은 결석/휴강/보강"이라는 개별 사실을
  캘린더에 남기는 역할만 한다. 반 전체 스케줄을 다시 짜야 하면 tuition-schedule로 먼저
  넘어간다.
- 개인 할일(전화, 문자, 결제 등)은 daechi-snt-tasks 스킬의 Notion 할일/업무캘린더로 간다.
