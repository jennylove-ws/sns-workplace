# 대치SNT학원 할일 → 노션 자동 기록

Jenny님이 대화 중에 학원 운영 할일을 언급하면 그 즉시 노션의 정해진 위치에 기록한다. "할일에 추가해줘"라고 하지 않아도 **학생/선생님 이름 + 처리할 액션(전화, 문자 발송, 결제, 확인, 구매/준비 등)**이 나오면 먼저 묻지 말고 바로 기록하고, 기록한 뒤 **한 줄로 어디에 넣었는지** 알려준다(조용히 넘어가지 않는다 — 잘못 분류됐으면 바로 고칠 수 있게).

## 0. 시작 전 반드시 확인

1. **Notion 연동 확인** — 도구 목록에 `mcp__Notion__*`이 있는지. 없으면 "지금 이 창에는 Notion 연동이 안 되어 있어서 자동으로 저장은 못 하고, 대화로만 도와드릴 수 있어요"라고 알리고, 노션에 손으로 옮겨 적을 수 있게 문구만 정리해준다.
2. **이 스킬 대상인지 확인 — daechi-snt-calendar와 구분한다.**

   | 내용 | 가는 곳 |
   |---|---|
   | 원장님 개인 업무: 전화, 문자 발송, 결제, 구매/준비 등 | **이 스킬** (Notion 할일/업무캘린더, 원장님 전용) |
   | 학생 결석, 선생님 휴강/보강, 학원 공식 일정(설명회·방학·시험기간 등) | **daechi-snt-calendar** (구글 캘린더, 행정팀과 공유) |
   | 한 문장에 둘 다 (예: "OO 결석 확인했고, 어머니께 전화하기") | 결석은 캘린더, "전화하기"는 이 스킬로 **나눠서** 기록 |

3. **날짜가 있는 일인지 판단** — "9/7일부터", "화요일에", "내일", "이번 주 토요일"처럼 날짜/요일이 있으면 → 2번(업무 캘린더). "언젠가 해야 할 일"이면 → 1번(할일 TASKS).
4. **중복 확인** — 기록 전에 대상 페이지/DB를 먼저 읽는다. 문구가 달라도 같은 학생·같은 용건이면 중복으로 보고 다시 넣지 않는다.
5. **기록 후 한 줄 확인** — 예) "할일(TASKS) → 전화할 것에 추가했어요: '수원외고 금액 확인'". 카테고리/섹션이 틀렸다고 하면 그 자리에서 옮긴다.

## 1. 날짜 없는 일 → "✅ 할일 (TASKS)" 페이지

- 페이지: `https://app.notion.com/p/39da9006a9ef8176bfe1c4686422c802` (id `39da9006-a9ef-8176-bfe1-c4686422c802`)
- 안 열리면(이동/재생성): ① **3층** "🏫 학원 운영 본부 (Claude 조직도)"(`https://app.notion.com/p/3c0a9006a9ef814e98b8c88003593f88`)의 "📅 날짜별 업무 캘린더" 섹션 → ② 실제로 들어 있는 **2층** "📚 2층 · 학사 운영 허브 (2학기 기준)"(`https://app.notion.com/p/39ca9006a9ef815489fced74a1314386`)의 "📅 일정 관리" 섹션 → ③ 거기도 없으면 "🏫 학원 업무" 목차 페이지(`https://app.notion.com/p/3e8a9006a9ef81a982c2ee48890b2d4b`)의 2층에서 "할일 (TASKS)" 링크를 다시 찾는다. (1층 "원자료 보관함"은 가공 전 자료 전용이라 할일·업무캘린더가 없다.)
- 페이지 안은 마크다운 체크박스 목록이다. **맞는 섹션 바로 아래에 `- [ ] 할일 내용` 한 줄을 새로 추가**한다(기존 줄은 절대 건드리지 않는다):

  | 섹션 | 넣는 일 |
  |---|---|
  | `## 오늘 할 일` | 사용자가 "오늘"이라고 **명시했을 때만** |
  | `## 전화할 것` | 전화/통화 |
  | `## 문자 발송할 것` | 문자/카톡 발송 |
  | `## 구매/준비할 것` | 물건 구매, 준비물, 주문 |
  | `## 나중에 할일` | 위 어디에도 뚜렷이 안 맞는 일반 할일의 기본 위치(급하지 않은 잡무) |
  | `## 이월된 일 (어제 못 한 것)`, `## 완료` | **새로 넣지 않는다** — 아침 브리핑/밤 자동 정리 대상 |

- 문구는 원문 어투를 살려 짧게, 기존 항목처럼 "학생이름 + 무엇을"(예: "박소진 샘 7~8월 같이 정산하기", "수원외고 금액 확인").

## 2. 날짜 있는 일 → "📅 업무 캘린더 (날짜별)" 데이터베이스

- DB: `https://app.notion.com/p/a82a2e017256402793dc74e6347eba63` (data source `collection://d6cea88b-81b2-46c8-a040-fde5383f6686`). 안 열리면 위 1번과 같은 페이지에서 다시 찾는다.
- 새 행 속성:
  - `업무` (title) — 할일 내용, 짧게
  - `날짜` (date) — 언급된 날짜/요일을 **오늘 날짜 기준으로 실제 날짜로 환산**("화요일", "다음 주" 등). 대충 넣지 않는다. 애매하면 날짜를 확인한다.
  - `카테고리` (select, 하나):

    | 카테고리 | 판단 기준 |
    |---|---|
    | 결제/카드 | 결제, 카드, 입금, 환불, 결제링크 발송 |
    | 전화 | 전화, 통화 |
    | 문자 | 문자, 카톡, 안내문 발송 |
    | 구매/준비 | 구매, 주문, 준비, 챙기기 |
    | 일정 | 수업/시간표/강의실 변경·배정, 보강 등 운영 일정 |
    | 기타 | 위 어디에도 뚜렷이 안 맞을 때 |
  - `메모` (text) — 학생 연락처, 배경 설명 등 부가 정보(없으면 비움)
  - `완료` (checkbox) — 새로 만들 때는 항상 미완료

## 3. 하지 말 것
- 학원 운영과 무관한 개인 잡담·메모를 억지로 노션에 적지 않는다.
- 노션 원본 서식(체크박스 마크다운, DB 속성 타입)을 바꾸지 않는다 — 있는 구조에 새 항목만 추가한다.
- 애매한 항목을 마음대로 각색하지 않는다 — 짧게 정리하되 학생 이름·핵심 용건은 그대로.

## ⚠ 과거에 실제로 있었던 문제
- 예전 버전은 페이지 **이름**은 "학사 운영 허브"라고 적고 **주소**는 학원 운영 본부(`3c0a9006...`)를 적어 이름과 주소가 달랐다(2026-09-29 정리). 비상 경로는 3층(학원 운영 본부)으로 통일한다 — AI가 3층부터 보는 구조이고, 그 페이지에 할일·업무캘린더 링크가 다 있다. 할일·업무캘린더는 2층 학사 운영 허브 안에 있다(2026-10-01 사용자 확인 — 1층으로 잘못 분류했다가 정정).
