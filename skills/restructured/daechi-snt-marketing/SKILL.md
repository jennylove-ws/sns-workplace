# 대치SNT학원 SNS·마케팅 콘텐츠

Jenny님이 주제나 상황(예: "중등 설명회 홍보글", "이번에 입시결과 나온 거 홍보", "S반 소수정예 강조해서 인스타 올릴 것")을 주면, 강조 포인트·타겟·톤을 판단해서 요청한 채널(들)의 콘텐츠 초안을 만든다. 여러 채널을 한 번에 요청하면 채널마다 순서대로 만든다.

## 0. 시작 전 반드시 확인 (놓치기 쉬운 것 먼저)

1. **이 스킬 대상인지** — 재원생 대상 운영 안내(회차확인, 수강료 안내, 강의실 안내, 미납 안내)는 `daechi-snt-messaging`. 이 스킬은 신규 모집·설명회·입시결과·강사진 홍보 같은 **대외 홍보** 전용이다. "학부모 발송용 문자"라도 홍보성(설명회·신규 모집 안내)이면 이 스킬, 이미 등록한 학생의 수강료/회차 안내면 messaging. 헷갈리면 확인한다.
2. **숫자(입시 결과, 정원, 가격 등)는 지어내지 않는다.** 사용자가 준 숫자만 쓰고, 없으면 "몇 명/몇 %인지 알려주시면 그대로 넣을게요"라고 묻는다. 강사 실적·이력도 사용자가 알려준 것만.
3. **아래 3가지 판단을 먼저 끝낸다.** 요청에 답이 있으면 다시 묻지 않고, 애매하면 **짧게 1번만** 확인한다(3개를 한 번에 물어도 됨). 잘못된 강조점/타겟으로 쓰면 다시 써야 하니 모르겠으면 반드시 먼저 묻는다.
   1. **상황/목적** — 중등 설명회, 고등 설명회, 특목고반(외고/국제고/과학고 등) 홍보, 재원생 간담회 안내, 입시결과 홍보, 신규 강사/커리큘럼 홍보, 시즌 모집(겨울방학 특강 등). `references/brand_info.md` "상황별 시나리오" 표 참고.
   2. **강조할 강점** (`references/brand_info.md` "강점 매핑"):
      - 소수정예/밀착관리 반(예: S반) → **소수정예·밀착관리**
      - 특정 유명 강사 수업 → **강사진 실적/이력**
      - 학원 전체/입시 시즌 → **입시 결과**
      - 특정 과목/반의 교재·수업방식 → **커리큘럼/교재**
      - 하나로 안 정해지면 "이번 건 뭘 제일 앞세울까요?"라고 묻는다(추측해서 엉뚱한 강점을 앞세우지 않는다).
   3. **타겟** — 중등 학부모 / 고등 학부모 / 특목고 지망 학부모 / 재원생(기존 학부모) / 일반(잠재 고객). 보통 상황에서 자동으로 정해진다("중등 설명회" → 중등 학부모).
4. **초안까지만 만든다.** 실제 게시 기능은 없다(연동된 게시 도구가 없으면). "바로 게시했다"는 식으로 말하지 않는다.

## 1. 채널별로 만들기

채널을 지정하면 그것만, "SNS에 다 올릴 것"처럼 포괄적이면 관련 채널(보통 블로그+맘카페+인스타) 전부. **포맷/톤/예시는 항상 `references/templates.md`를 보고 지킨다.**

| 채널 | 톤 (기본값, 상황에 따라 조정) | 핵심 |
|---|---|---|
| 블로그 (네이버 블로그) | 신뢰감 있고 정보 중심, 데이터/실적 근거 | 제목 후킹 → 공감 도입 → 근거+강점 본문 → CTA → 해시태그 |
| 맘카페 | 친근한 구어체, 광고 느낌 최소화(후기/정보 공유하듯) | 과장 광고 문구 지양, 실제 학부모가 쓴 것처럼 |
| 인스타그램 | 짧고 임팩트, 트렌디 | 캡션 + 해시태그 블록 + 카드뉴스 이미지 문구 |
| 유튜브 | 숏폼은 캐주얼/훅, 롱폼(설명회 다시보기 등)은 정보 중심 | 대본(숏폼) 또는 챕터 아웃라인(롱폼) |
| 학부모 발송 홍보 문자 | 격식 있는 안내문투 (messaging과 동일한 브랜드 태그·문의처 규칙) | `[대치SNT]` 태그, 문의처/카카오채널 블록 |

## 2. 마케팅 전략 짜기

"마케팅 전략 짜줘", "이번 시즌 어떻게 홍보할까"면 콘텐츠 대신(또는 같이) 이 구조로 짠다(`references/templates.md` 6번 표 형식):
1. **목표** — 신규 모집 / 설명회 참석 유도 / 브랜드 인지도 / 재원생 유지
2. **타겟** — 0-3-3 기준
3. **핵심 메시지(강조점)** — 0-3-2 기준, 여러 개 조합 가능
4. **채널믹스 & 타이밍** — 어떤 채널을 언제(설명회 전/중/후), 우선순위
5. **콘텐츠 캘린더** — 날짜/채널/주제 표. 일정이 정해져 있으면 daechi-snt-tasks의 업무 캘린더에도 등록할지 묻는다.
6. **CTA/전환 유도** — 설명회 신청, 카카오 채널 추가, 전화 문의 등

- 여러 채널을 줄 때는 채널마다 구분선(`---`)으로 나눠 어디부터 어디까지가 어떤 채널용인지 표시한다.
- 브랜드 표기는 `[대치SNT]`(성빈 등 다른 이름 쓰지 않음), 문의처 031-895-5003, 카카오 채널 `https://pf.kakao.com/_ijRXX`. 바뀌었을 수 있으니 daechi-snt-messaging의 `references/templates.md`와 Notion "문자양식 라이브러리"에서 최신 값을 확인한다.
- 초안 뒤에 "이대로 쓰셔도 되고, 톤/강조점 다르게 원하시면 말씀해주세요" 정도로 한 줄 — 광고 콘텐츠는 사람이 최종 검수한다.
