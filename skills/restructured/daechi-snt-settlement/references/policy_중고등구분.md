# 정산 방식: 중고등구분 (고등 50% / 중등 40%)

공통 규칙(표 구조·출결 코드·학교 처리·레이아웃·스타일)은 `SKILL.md`를 따르고, 여기서는 이 방식만의 규칙을 정의한다.

적용 대상: 맥심T, 박선애T.

## 1. 구분 판정 규칙 — 반 이름이 아니라 "학생 개별 학교명"으로 판정

반 이름(예: "예비고1")만으로는 실제 학년을 알 수 없고, 같은 반에 중3·고1이 섞여 있을 수도 있다. 판정 순서:

1. **① `assets/student_roster.xlsx`에서 학생 이름으로 학교를 찾는다.** 있으면 학교명 접미사로 자동 판정 (`◯◯중` → 중등, `◯◯고` → 고등).
2. **② 명부에 없는 새 학생은 반 이름의 학년 표기**(중1/2/3=중등, 고1/2/3=고등, "예비고1"=중3 취급 → 중등)로 1차 판정하되 애매하면 확인.
3. **③ 그래도 판정 불가면 노란색**으로 표시하고 사용자에게 확인 요청. 확인되면 정산파일과 `student_roster.xlsx` 양쪽에 반영.

## 2. 반별 구분·정산액 자동계산 표

정산내역 바로 위에 반(표) 하나당 한 줄씩 배치:
- 반: 반 이름
- 구분: `고등` 또는 `중등` (파란 글씨, 하드코딩 — 1번 규칙으로 판정한 값)
- 실입금액: 해당 반 표의 실입금액 합계 셀을 수식으로 연결
- **정산액(②)**: `=ROUNDUP(실입금액 * IF(구분="고등", 고등비율셀, 중등비율셀), -1)`

비율 정책 표(고등 50% / 중등 40%)는 셀로 분리해 보관 — 정책이 바뀌면 이 셀만 수정하면 전체에 자동 반영.

## 3. 정산내역 최종 계산

```
① 실입금액 합계               = SUM(반별 표의 실입금액 열)   ※ 참고용, 계산에는 미사용
② 정산액 합계 (반별 자동계산 합) = SUM(반별 표의 정산액(②) 열)
③. 사업소득세 3.0%            = ROUNDDOWN(② * 3%, -1)
④. 지방소득세 0.3%            = ROUNDDOWN(② * 0.3%, -1)
지급액 (②-③-④)               = ② - ③ - ④
```

- 반별로 ROUNDUP을 각각 적용한 뒤 합산하므로, 전체에 한 번에 ROUNDUP 적용할 때보다 반 개수만큼(최대 반당 10원) 더 커질 수 있다. 오차가 문제되면 사용자에게 먼저 확인한다.
- 사업소득세·지방소득세는 고등/중등 구분 없이 ② 합계 전체에 대해 한 번만 계산한다.
