# 정산 방식: 60% (비율 60%)

공통 규칙(표 구조·출결 코드·학교 처리·레이아웃·스타일)은 `SKILL.md`를 따르고, 여기서는 정산내역 계산 공식만 정의한다. [기본 방식](./policy_기본.md)에서 **"② ①의 비율 50%"를 "60%"로만 바꾼** 변형이다.

적용 대상: `teacher_policy.md`에서 방식이 "비율 60%"인 선생님 (2026-08 기준 박민수T, 서현수T, 윤재필T).

```
① 실입금액        = 모든 반 표의 "실입금액 합계"를 더한 값
② ①의 비율 60%    = ROUNDUP(① * 60%, -1)
③ ②의 사업소득세 3.0%  = ROUNDDOWN(② * 3%, -1)
④ ②의 지방소득세 0.3%  = ROUNDDOWN(② * 0.3%, -1)
지급액 (②-③-④)    = ② - ③ - ④
```

- ROUNDUP/ROUNDDOWN의 `-1` 자리수(십 원 단위 절상/절사)는 기본 방식과 동일하게 유지한다.
- 사업소득세(3.0%)·지방소득세(0.3%) 세율은 비율과 무관한 회사 공통 정책이므로 바꾸지 않는다.
- 그 외 전체 파일 구조, 출결 코드, 학교 정보 처리, 레이아웃(반별 표 제목에 합계 표시·정산내역 좌측 압축 배치·이름/학교 열 틀 고정), 스타일은 `SKILL.md`를 그대로 따른다.

*최초 작성: 2026-08-02, 박민수T·서현수T·윤재필T 파일에 비율 60% 적용 요청에 따라 기본 지침에서 분리.*
