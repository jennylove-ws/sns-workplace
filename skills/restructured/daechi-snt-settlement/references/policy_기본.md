# 정산 방식: 기본 (비율 50%)

공통 규칙(표 구조·출결 코드·학교 처리·레이아웃·스타일)은 `SKILL.md`를 따르고, 여기서는 정산내역 계산 공식만 정의한다.

```
① 실입금액        = 모든 반 표의 "실입금액 합계"를 더한 값
② ①의 비율 50%    = ROUNDUP(① * 50%, -1)
③ ②의 사업소득세 3.0%  = ROUNDDOWN(② * 3%, -1)
④ ②의 지방소득세 0.3%  = ROUNDDOWN(② * 0.3%, -1)
지급액 (②-③-④)    = ② - ③ - ④
```

적용 대상: `teacher_policy.md`에서 방식이 "기본"으로 지정된 모든 선생님 (신영준T, 엄형국T, 우지훈T, 정수인T, 허지원T 등). 박주신T는 과거 이 방식으로 분류되어 있었으나 2026-08-22 확인 결과 시급제로 정정되었다 — `policy_시급제.md` 참고.
