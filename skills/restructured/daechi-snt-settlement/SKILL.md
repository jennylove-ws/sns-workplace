# 대치SNT학원 출석부 → 정산파일 작성

학원 강사 출석 결과 엑셀(원본, 열 병합 없는 raw export)을 받아 대치SNT학원 표준 형식의 **정산 파일(반별 표 + 정산내역)**을 만든다. 신영준T/엄형국T 파일 작업에서 확립된 규칙을 따른다.

## 0. 시작 전 반드시 확인 (하나라도 모르면 멈추고 묻는다)

1. **선생님·반 이름** — 출석 결과 파일 A열 `학급명`.
2. **정산 방식** — `references/teacher_policy.md`에서 선생님을 찾는다(**명단은 이 파일이 유일한 기준**).
   - 있으면 그 방식(기본50% / 60% / 중고등구분 / 합계만 / 시급제)을 그대로 적용.
   - **없으면 절대 50%로 가정하지 않는다.** 어떤 방식인지 먼저 묻고, 확정되면 `teacher_policy.md`에 행을 추가한다.
   - **시급제 선생님은 시급이 아직 미확정**이다(`references/policy_시급제.md`). 시급/계산식을 사용자가 알려주기 전까지 **최종 지급액 계산을 하지 않는다**(회차·출결 정리만 가능하다고 안내).
3. **회당 단가** — 출석 결과 파일에는 없다. 이 순서로 찾고, 없으면 묻는다(추측 금지):
   1. **Notion·Google Drive 연동이 있으면 최우선**: Notion "🏫 학원 운영 본부 (Claude 조직도)"(`https://app.notion.com/p/3c0a9006a9ef814e98b8c88003593f88`) → "팀 1. 시간표·수강료팀장" 또는 "팀 2. 정산·회계팀장" 섹션에 링크된 최신 "OO학기 수업 회차 & 수강료 (원본 문서)" 구글독스. 이 한 파일에 회차·수강료와 강의실배정이 같이 있다. **읽기 전용 — 직접 고치지 않는다.** 허브 페이지가 매 학기 최신 링크로 갱신되므로, 개별 구글독스 URL을 이 스킬에 하드코딩하지 않고 항상 허브를 거친다.
   2. 위 방법을 못 쓸 때만 프로젝트에 첨부된 회차·수강료 문서를 참고한다. ⚠ 2026-08-22 확인 결과 프로젝트 사본이 최신 구글독스와 반명·강의실이 다른 경우가 있었다(예: 신영준T "유신/창현B" 반 누락, 일부 강의실 번호 불일치). **둘이 다르면 항상 Notion 경유 원본을 따른다.** 프로젝트 파일이 없으면 건너뛴다.
   3. 그래도 없으면 사용자에게 단가를 묻는다.
4. **처음 보는 출결 코드**(4번 표에 없는 코드)가 있으면 임의로 판단하지 말고 의미를 묻는다.
5. 파일이 openpyxl로 안 열리면(styles.xml 오류 등) 아래 "기술 노트"의 LibreOffice 복구부터.
6. **구글독스/구글시트 원본은 항상 읽기 전용.** 결과물은 항상 새 파일(정산 xlsx)로 만든다.

## 1. 작업 순서 (체크리스트)
1. 출석 결과 파일에서 반 이름/학생 명단/날짜별 출결 코드 확인.
2. `teacher_policy.md`에서 방식 확인 (없으면 묻고 기록).
3. 단가 확인 (임의 가정 금지).
4. 처음 보는 출결 코드가 있으면 의미 확인.
5. 출결 코드를 4번 규칙대로 1/빈칸(색상 포함)으로 변환.
6. 반별 표 작성(병합 없이 1행=1학생), 기존 표 아래(또는 지시대로 위)에 이어 붙임.
7. 학교 정보: `assets/student_roster.xlsx` → 이번 세션의 다른 표 → Notion 경유 학생 명부 → 없으면 노란색.
8. 정산내역 섹션을 선생님 방식 공식으로 연결, 왼쪽에 좁게 배치.
9. 모든 값은 수식으로(하드코딩 금지 — 단가만 파란 글씨 입력값).
10. LibreOffice로 재계산해 수식 오류 0개 확인 후 전달(기술 노트).
11. 새로 확인된 학교 정보는 `assets/student_roster.xlsx`에 추가.

## 2. 전체 파일 구조
- **반(과목)별로 표를 분리**해 아래로 이어 붙인다(병합하지 않음). 학급명이 다르면(같은 "브릿지" 파일 안의 "2시"/"7시"처럼) 별도 표.
- 표 순서: 특별한 지시가 없으면 최근 반이 위, 기존 표는 아래.
- 표 제목은 `① [반 이름]`, `② [반 이름]`(원 번호).
- **표 제목 줄에 학생 수·실입금액 합계를 수식으로 표시**: `① [반 이름]  (총 N명 / 실입금액 합계 8,007,375원)` — TEXT()로 합계 셀을 이어붙인 수식.
- 맨 아래 전체 반을 합산하는 **【정산내역】**.

## 3. 표 컬럼 (반별 공통, 병합 없음 — 1행=1학생, 1열=1항목)

| 컬럼 | 내용 |
|---|---|
| No. | `=ROW()-시작행` (하드코딩 금지) |
| 이름 | 신규/중도입학생은 `이름(신)` + 셀 메모(comment) "M/D(요일)\t수강시작" |
| 학교 | 5번 참고 |
| 날짜별 출석 (여러 열) | 실제 수업일만큼만 열 생성. 출석=`1`, 미포함=빈칸(색상은 4번) |
| 출석횟수 | `=COUNTA(날짜범위)` |
| 단가 | 사용자 확인값, **파란 글씨** |
| 실수강료 | `=출석횟수*단가` |
| 납부방법 | 기본 "카드" |
| 실입금액 | `=IF(납부방법="카드",0.978*실수강료,실수강료)` |

데이터 행은 **절대 병합하지 않는다**(필터/정렬/수식 참조). 병합은 "합계"·"정산내역"처럼 라벨+숫자 하나만 보이는 요약 행에서만.

## 4. 출결 코드 → 회차 산정 (고정)

| 코드 | 회차 포함 | 비고 |
|---|---|---|
| 출 / 지 / 통결 / 결석 / 결 | ✅ 포함 | 전부 영상보강 진행 전제 |
| 출(시작) / 결(시작) / 출(신규) | ✅ 포함 (그 날짜부터) | 이름에 `(신)`, 셀 메모 "M/D 수강시작" |
| 미 | ❌ 미포함, **노란색** | 출결 미확인 — 나중에 확인 필요 |
| 전반 / 휴원 / 퇴원 / 영상보강 없음 | ❌ 미포함, **연한 블루** | 등록 전/일시정지/중도퇴원/보강없음 |
| 처음 보는 코드 | — | 임의 판단 금지, 의미 확인 |

- 규칙에 없어 그냥 빈 칸으로 남는 날짜(등록 전 등)도 **연한 블루**.
- "목요일 클리닉은 아예 회차 대상 아님"처럼 요일 제외 지시를 받으면 그 요일 **열 자체를 제거**한다(빈 칸으로 두지 않음).

## 5. 학교 정보 (연락처 대신 학교)
- 원본엔 보통 전화번호만 있다. **개인정보 보호 + 확인 목적**으로 학교 컬럼을 쓴다(연락처는 안 씀).
- 찾는 순서: ① `assets/student_roster.xlsx`(학생 명부) → ② 이번 세션에 처리한 다른 T 파일의 같은 학생 → ③ Notion·Drive 연동이 있으면 "🏫 학원 운영 본부 (Claude 조직도)" → "팀 2. 정산·회계팀장"의 "학생 명부(최신)" 구글시트(읽기 전용) → ④ 없으면 **노란색 배경**으로 비우고 확인 요청.
- **새로 확인된 학교는 반드시 `assets/student_roster.xlsx`에 행을 추가해 누적**한다(다음에 재사용).
- 동명이인 가능성이 있으면(확신이 안 서면) 채우지 않고 확인한다.

## 6. 정산내역 — 선생님 방식별 (공식 상세는 references/)

| 방식 | 문서 | 핵심 공식 |
|---|---|---|
| 기본 | `references/policy_기본.md` | ②=ROUNDUP(①×50%,-1) |
| 60% | `references/policy_60퍼센트.md` | ②=ROUNDUP(①×60%,-1) |
| 중고등구분 | `references/policy_중고등구분.md` | 반별로 학생 구분(고등50%/중등40%) 자동계산 후 합산 |
| 합계만 | `references/policy_합계만.md` | 비율 단계 없이 ①에서 바로 세금 공제 |
| 시급제 | `references/policy_시급제.md` | **기준 미확정 (2026-08-22).** 확정 전까지 진행하지 않음 |

- **세금(사업소득세 3.0%, 지방소득세 0.3%, 둘 다 `-1`자리 절사)은 시급제를 제외한 네 방식 공통**, 항상 적용. 시급제는 세금 공제 여부 자체가 미확인.
- 중고등구분은 **반 이름이 아니라 학생 개별 학교명**으로 판정(순서는 `policy_중고등구분.md` 1번). "예비고1" 반은 실제로 중3이므로 중등(40%).

## 7. 레이아웃 (스크롤 없이 한눈에)
- 반별 표 **제목 줄에 실입금액 합계 수식**(2번).
- **【정산내역】은 표 전체 너비가 아니라 왼쪽에 좁게**(예: A~F열 라벨, G~K열 금액) — 표가 넓어져도 스크롤 없이 보이게.
- **No./이름/학교 열 틀 고정(freeze_panes)**.

## 8. 스타일
- 폰트: 나눔바른고딕 Light(본문) / 굵게(헤더·합계·지급액)
- 하드코딩 입력값(단가): **파란 글씨**
- 학교 미확인 / 미확인('미') 날짜: **노란색 배경**
- 회차 미포함(전반/휴원/퇴원/등록전 등): **연한 블루**(`DDEBF7`)
- 헤더 행: 회색 배경 + 굵게 / 합계·요약 행: 연한 회색 배경 + 굵게
- 금액: `₩#,##0` (음수는 빨간 괄호)

## 9. 기술 노트
- 아래 `/mnt/skills/public/xlsx/...`는 claude.ai 기준 경로다. 없으면 xlsx 스킬 폴더의 `scripts/`를 찾아 같은 파일을 쓴다.
- **openpyxl로 안 열리는 원본/과거 정산파일**(styles.xml `IndexError` 등): LibreOffice로 먼저 복구.
  ```bash
  python3 /mnt/skills/public/xlsx/scripts/office/soffice.py --headless --convert-to xlsx --outdir repaired <원본파일>.xlsx
  ```
- **새 정산 파일은 openpyxl로 직접 작성**(병합 셀, 서식, 수식 문자열). `scripts/build_settlement.py`의 `build_table` 헬퍼를 복사해 이름/학교/단가/출결만 바꿔 쓴다(그대로 실행하는 파일이 아님).
- **저장 후 반드시 재계산**:
  ```bash
  python3 /mnt/skills/public/xlsx/scripts/recalc.py <파일>.xlsx 90
  ```
  `total_errors`가 0인지 확인하고, `data_only=True`로 핵심 셀 값을 손계산(반별 합계 등)과 대조한 뒤 전달.
- 레이아웃을 눈으로 보려면 PDF로 변환:
  ```bash
  python3 /mnt/skills/public/xlsx/scripts/office/soffice.py --headless --convert-to pdf <파일>.xlsx
  ```

## ⚠ 과거에 실제로 있었던 실수 (검수할 때 꼭 볼 것)
- 사업소득세·지방소득세 중 하나만 `ROUNDDOWN(...,0)`으로 잘못 입력된 적이 있다(엄태욱T) → 둘 다 `-1`인지 확인.
- 박주신T가 예전에 기본(50%)으로 잘못 분류돼 있었다 → 2026-08-22 시급제로 정정. 과거 방식으로 다시 계산하지 않는다.
- 프로젝트 첨부 회차·수강료 사본이 최신 원본과 달랐다 → 단가·반명은 Notion 경유 원본 우선(0-3).
